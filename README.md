## 📌 Task Objective
Create visuals around four specific business questions requested by the CEO and CMO, using **Power BI**. Perform data cleanup before analysis to ensure accurate and reliable results.

---

## 🛠 Data Cleanup Steps
Before creating the visuals:
1. **Quantity Check** – Exclude rows where `Quantity < 1`.
2. **Unit Price Check** – Exclude rows where `Unit Price < 0`.
3. Used **conditional formulas** and **data transformation** in Power BI to remove invalid records.

---

- Highlights seasonal trends to assist in forecasting.
