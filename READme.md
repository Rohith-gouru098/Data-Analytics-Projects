### Key Modules & Insights

**1.  Sales & Operational Profitability Dashboard**

- KPIs: Total Sales, Operational Profit, Profit Margin %, Return Rate %

- Region & Segment matrix with conditional formatting (green = profit, red = loss).

- Top 5 products by profit using DAX Top N filtering.

**2. Discount Impact & Profit Correlation**

- Measures discount vs. profit correlation using Pearson method in DAX.

- Scatter plot with trend line showing effect of discounts on margins.

- Flagged loss-making categories due to heavy discounting.

**3. Logistics & Delivery Performance**

- KPIs: Avg Delivery Days, On-Time Delivery Rate %, Delivery–Profit Correlation.

- Map and bar chart visualizing region-wise delivery efficiency.

- Delivery buckets (0–3, 4–7, 8+ days) highlighting bottlenecks and late shipments.

**4. Returns & Customer Retention Analysis**

- KPIs: Return Rate %, Repeat Customer Rate %, Orders per Customer.

- Bar & table visuals identifying top products and reasons for returns.

- Segmented retention analysis by region and customer type.

**5. Pareto (80/20) Product & Category Analysis**

- Built in Power Query with cumulative profit and 80% cutoff line.

- Combo chart (bar + line) showing top 20% products contributing ~80% of profit.

- Time-based slicers (Year, Quarter, Month) for profitability trends.

### 🧮 Key KPIs Tracked

- Financial: Total Sales, Operational Profit, Profit Margin %, Revenue per Category

- Customer: Repeat Customer Rate, Orders per Customer

- Operational: On-Time Delivery %, Avg Delivery Days, Return Rate %

- Analytical: Discount–Profit Correlation, Delivery–Profit Correlation

### 🛠️ Tools & Technologies

- Power BI Desktop (Data Modeling, DAX, Visualization)

- Power Query (M language) for data transformation

- Excel (.xlsx) for input dataset

- PDF for task brief and KPI definitions

### 🚀 Outcome

A dynamic, interactive dashboard that helps stakeholders identify:

- High-revenue but low-margin regions

- Discount-driven losses

- Logistics bottlenecks

- Customer segments with high return or retention risk

- Top 20% products driving 80% profits
